# Barbell Diva v145.1 — Coach tools

Questa cartella è pronta per GitHub Pages e parte dalla v145 stabile.

## Novità recuperate in modo sicuro

- copia di una settimana in un'altra;
- progressione percentuale facoltativa dei carichi;
- annullamento immediato dell'ultima copia;
- confronto tra due settimane;
- grafico trend dell'intero programma;
- sostituzione rapida cliccando il nome dell'esercizio;
- animazioni leggere, limitate alle nuove finestre.

La navigazione Coach, le Statistiche, l'Anteprima atleta laterale, il salvataggio
locale/cloud esistente e la cache PWA della v145 restano invariati.

Non sono presenti le chiamate `/api/coach/state`, gli observer globali e i file
temporanei della versione ricevuta dall'altro agente.
